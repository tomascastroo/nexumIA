# Multicanal (Email/SMS/WhatsApp)

Descripción: Permitir orquestación de mensajes vía múltiples canales con prioridades y fallback.

Criterios de aceptación:
- [ ] Configurar canales por campaña/estrategia
- [ ] Reglas de fallback (si WhatsApp falla, enviar SMS)
- [ ] Métricas por canal y tasa de entrega
